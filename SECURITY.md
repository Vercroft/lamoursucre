# Security policy

## Reporting a vulnerability

Please report it privately through GitHub: open this repository's **Security** tab, choose
**Report a vulnerability**, and describe the problem
([how private vulnerability reporting works](https://docs.github.com/en/code-security/security-advisories/guidance-on-reporting-and-writing-information-about-vulnerabilities/privately-reporting-a-security-vulnerability)).
Do not open a public issue for a vulnerability.

This is a static website with no server code, no accounts and no stored data. The most relevant reports are
problems in the build and deploy workflows or in the site's security headers.

Secrets and tokens never belong in this repository; see [docs/SECURITY.md](docs/SECURITY.md).
